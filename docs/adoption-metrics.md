# 채택·응답 지표

라이브러리가 실제로 쓰이고 있는지, 이슈에 얼마나 빨리 답하는지를 도구 수나
인상이 아니라 **수집 방법이 명시된 숫자**로 기록한다. 수치는
`scripts/snapshot_adoption_metrics.py` 실행 시점의 스냅샷이며, 기계 판독
이력은 [adoption-metrics-history.json](https://airmang.github.io/python-hwpx/adoption-metrics-history.json)에
쌓인다(같은 날 재실행은 그날 항목을 교체 — 멱등).

| 이슈 첫 응답 중앙값 | 47.8시간 (최악 195.8시간) | 소유자 첫 코멘트(없이 닫힌 경우 닫힌 시각) | 공개 타임라인 밖의 응답은 보이지 않는다 |
| 외부 커밋 기여자 | 6명 | GitHub contributors, 소유자 제외 | 커밋 귀속 기준 — 리뷰·이슈 기여는 미포함 |

## 측정 정의

- **첫 응답**: 외부 작성 이슈의 생성 시각부터, 소유자의 첫 공개 코멘트까지.
  코멘트 없이 닫혔으면 닫힌 시각을 응답으로 센다. 응답이 아직 없는 열린
  이슈는 `unansweredOpenCount`로 따로 집계한다.
- **외부**: 이슈/커밋의 작성자 로그인이 저장소 소유자(`airmang`)가 아닌 경우.
- 표본이 없는 지표는 0이나 평균으로 눙치지 않고 `null`과 사유를 기록한다.

## 왜 이렇게 재나

채택은 도구 수나 인상이 아니라 공개 피드백으로 측정한다는 원칙의 실행이다
(공개 약속: [tracking issue #71](https://github.com/airmang/python-hwpx/issues/71)).
이 페이지가 그 측정의 공개 표면이고, [실측 코퍼스
메트릭](corpus-metrics.md)이 산출물 품질의 공개 표면이다.
